# 問いから図種・配置・図説明を決める

まず比較対象と独立した観測単位を特定する。行動課題では試行が参加者に、電気生理ではスパイクがニューロンに、ニューロンが動物に入れ子になる。どの単位で平均や区間を計算したかを記録する。同じ測定値でも「群に差があるか」「同じ個体がどれだけ変わったか」「どの値をとる個体が多いか」では図が変わる。

| 読者に判断してほしいこと | 向いている図と、その理由 | 軸・図説明に必要な情報 |
|---|---|---|
| 刺激の強さで選択がどう変わるか | 選択の実測割合を点、適合した心理測定関数を線にする。条件差が主題なら参加者ごとの閾値・傾きも比較する | 例：`Signed motion coherence (%)` × `Rightward choices (%)`。方向選択率と正答率を区別し、試行数、ビン、適合関数を図説明に書く。偶然水準は課題から決める |
| 反応時間の典型値と遅い試行の裾はどう違うか | 典型値は参加者内の中央値を条件間で結ぶ。裾や分布が主題なら経験累積分布関数（ECDF）や分位点を比較する。速度と正確さを併せて問うなら同じ横軸で正答率も示す | `Response time (ms)`。計時の基準、正答のみか全試行か、除外基準、参加者数と試行数、参加者内・参加者間での集約順を区別する |
| 発火が刺激・運動のどちらに同期するか | 1ニューロンの試行別ラスタと同じ時間軸のPSTH（事象にそろえた発火率の推移）を並べる。集団なら細胞×時間のヒートマップを加える | `Time from stimulus onset (s)`、`Trial`、`Firing rate (spikes/s)`。時刻ゼロ、ビン幅・平滑化、条件別試行数、細胞数と動物数を記す |
| ERPやカルシウム信号はいつ・どれだけ変わるか | 波形と帯を事象にそろえ、解析した時間窓を示す。差が主題なら参加者・動物ごとの窓平均や差分波形を隣に置く | `Amplitude (µV)` または `ΔF/F₀ (%)`。事象関連電位（ERP）の極性・電極・基準区間、蛍光の基準値、帯を求めた独立単位を記す。クラスタ検定だけで効果の開始時点を特定しない。[Sassenhagen & Draschkow](https://doi.org/10.1111/psyp.13335) |
| 独立した群で値はどれだけ違うか | 少数標本では全点を並べる。差が主題なら群間差と信頼区間も添える。多数なら箱ひげ図に点を重ね、分布の形が主題ならバイオリンプロットやECDFを使う | 横に群、縦に測定量と単位。1点の単位、群別のn、中心と区間の定義。少数点から描いた密度は平滑化に左右される |
| 同じ対象が前後でどう変わったか | 同じ対象の2点を線で結ぶ。絶対変化が主題なら対象別の差をゼロ基準で並べる | 対応を表すID、差の向き、完備ペア数。片方しか測れなかった対象は観測した側の点で示し、対応差の集計からは除く |
| 多数の細胞を少数の個体・培養から採ったとき、結果は標本間でも一貫するか | 細胞の点と、個体ごとの要約値を別の大きさ・形で重ねる。条件が個体内で対応すれば個体の要約値同士を結ぶ | 細胞数と独立した個体数を分ける。区間の推定や検定は割付・標本抽出の単位と階層構造に合わせる。[Lord et al.](https://rupress.org/jcb/article/219/6/e202001064/151717/SuperPlots-Communicating-reproducibility-and) |
| 時間の中でいつ変化したか | 同じ対象は時系列の線で追う。繰り返しが多ければ個体の線に要約線を重ねるか、小分けにする。時点ごとに別標本なら個体の軌跡は作らない | 横に実時間、縦に値。処置時点、観測の空白、時点別n、帯の定義。補間、平滑化、予測は判別できるようにする |
| 2量に関係があるか、2手法は同じ値を返すか | 関係には散布図。等しい単位で一致を問うなら等値線を入れ、系統差を見るなら差対平均の図を検討する | 各軸の単位、点の単位。等値線、回帰線、信頼帯を区別する。高い相関だけでは一致の根拠にならない |
| 効果の大きさと不確かさはどう違うか | 比較項目を縦に並べ、点と区間を同じ横軸で読む。異なる単位の係数なら標準化の妥当性を確かめる | 差・対数比の帰無値は0、比の帰無値は1。比は対数目盛も検討する。基準群、効果の単位、区間の水準と算出法 |
| 割合・構成はどう違うか | 特定の割合を群間で比べるなら共通軸の点、全体の内訳なら100%積み上げ棒。数そのものが主題なら度数で描く | 分子と分母、除外・未分類の扱い、群別の総数。母集団の大きさが異なると件数と割合で解釈が変わる |
| 神経組織や細胞内の局在に差があるか | 顕微鏡は対照と対象を同じ表示条件で並べる。拡大範囲を枠で結び、必要なら全標本の定量を隣に置く。組織切片は向きと解剖学的な位置をそろえる | 校正したスケールバー、チャネル名、疑似カラー、画像選択基準。細胞・視野・個体の数と関係 |
| 行列や高次元データのどこにパターンがあるか | 特徴×標本ならヒートマップ、近傍の構造を見るなら埋め込み。差を主張する対象は、元の単位で読める図も添える | 行列の行・列・並び順、変換と色の範囲。行ごとのz値では特徴間の絶対量を比較できない。埋め込みの島の面積を標本の割合として読まない |
| 遺伝子発現の差はどれほど大きく、どの程度確かか | 多数の遺伝子の概観にはボルケーノプロット、平均発現量に依存した変化の確認にはMAプロット、特定遺伝子の比較には生物学的標本ごとの発現量を示す | 例：`log₂ fold change (treated/control)` と `−log₁₀(adjusted P value)`。比較の向き、補正法、閾値の根拠、未検定値を記す。単一細胞データで群差を推論するときはドナー数と細胞数を分ける |
| 脳のどこに活動差が見られるか | 同じ方向・座標の断面または脳表に効果量や検定統計量を重ねる。群間差の大きさを読むなら、独立に定めたROIで参加者ごとの値も示す | 左右、座標系、断面位置、カラーバーの量（例：`t statistic`）、表示閾値と多重比較補正。色のない領域が未測定か閾値未満かを説明する |
| 手法の性能はどの条件で落ちるか | 基準法を含む閾値曲線、条件別の分布、失敗例に役割を分ける。陽性が少ない分類では適合率・再現率曲線も候補 | 評価対象、テスト標本数と単位、基準値、閾値、平均化の方法。画像例と全テスト標本の集計を見分けられるようにする |

棒の高さで量を表すときは原則ゼロを含める。点や区間の差を精読させるときは、必要な範囲を選び、目盛と基準線を明示する。群の平均と誤差棒だけにすると、外れ値、群内の分布、前後の対応が読めなくなる。[Weissgerber et al.](https://journals.plos.org/plosbiology/article?id=10.1371%2Fjournal.pbio.1002128)

## 主図に残すもの

- **比較だけで答えが出るとき**は1パネルでよい。値が一つで本文の一文で伝わるなら文章、正確な数値を何度も引く用途なら表を候補にする。
- **測り方が判断に効くとき**は最小限の模式図または代表画像を定量の隣に置く。例の出所、測定箇所、対応する点を識別できるようにする。代表例だけから頻度や群間差を主張しない。
- **比較が複数あるとき**は行を測定項目、列を条件とするなど、一方向に同じ意味を持たせる。直接比較する軸は範囲・目盛・並びをそろえる。条件が一致しないパネルはその場に注記する。結論を左右する対照や感度分析は主図に残し、補足的な検証や網羅的内訳は別図に回せる。
- **色の使い分け**は、カテゴリなら区別しやすい色＋形や線種、量なら明度が順に変わる配色、正負なら意味のある中心を持つ発散配色。ゼロ・欠測・測定限界以下を同色にしない。比較する画像やヒートマップは同一の表示範囲を使うか、範囲の違いを明示する。

## 軸、凡例、figure legendに書き分ける

軸には「変数（単位）」を書く。例えば `Time after stimulation (min)` や `Responding cells (%)` とし、後者の分母は図説明で定める。正規化では基準群・基準時点、対数では「値を変換した軸」か「元の値を対数目盛で表示した軸」かが読める表記にする。単位のない相関係数には単位を付けない。桁数は測定精度に合わせる。

図中の凡例（key）は記号見本と短いラベルにする。系列が少なければ線の終点に条件名を置ける。figure legendは独立して読めるよう、短い図題、パネル順の説明、点・線・区間の定義を記す。SDは標本のばらつき、SEMは平均の標準誤差、CIは推定した量の区間であり、目的に合わせて選ぶ。箱ひげの定義、群別の正確なnとその単位、対応の有無、検定を行った場合の手法・多重比較補正も該当箇所に結びつける。図に示した記号やP値の意味が復元できる形にする。

**英文figure legendの例（架空の実験心理データ）**

“Response times with and without a cue. **a**, Each point shows one participant’s median response time on correct trials. Lines connect conditions for the same participant. **b**, Within-participant difference in median response time (cued minus uncued). Each point represents one participant (n = 6). The dashed line marks zero difference. Data are simulated.”

この例でbの横線を平均や95%信頼区間に変更するなら、その意味と算出法も図説明に加える。区間や検定を本当に計算したときだけ書く。
